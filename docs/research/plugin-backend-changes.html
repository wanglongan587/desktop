插件通道（host ↔ plugin 之间）的通信帧格式：。

：type 1 字节（payload 内容选择器，当前 1=JSON，预留 2=file 等）+ length 4 字节（payload 字节数，不含帧头，大端序）。总帧大小 = 5 + length。

：
  • 换行分隔（）的问题：payload 含 会断帧；长度前缀是二进制安全的（payload 可含任意字节）。
  • 业界模式（gRPC 的 、WebSocket 的 opcode 分派）：帧层按 type 分派，应用层只看到类型化消息。
：不用 （默认 8 字节，i8 后 3 字节 padding）；也不用 （5 字节但有引用 UB 风险）。改用手动写字节（ → 正好 5 字节，无 padding，无对齐 UB）。

  • / 是通用的——读/写任何 type 的帧，不硬编码 type=1。
