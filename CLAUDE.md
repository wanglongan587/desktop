## Agent skills

### Issue tracker

Issues live as GitHub issues on the `origin` remote (`wanglongan587/desktop`); `gh` infers the repo automatically. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical triage labels, strings equal to their names (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one root `CONTEXT.md` + `docs/adr/`. See `docs/agents/domain.md`.
